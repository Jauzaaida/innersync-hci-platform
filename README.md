# InnerSync HCI Platform

Personality-adaptive emotional wellness platform with emotional analytics and intelligent human-centered interaction.

---

## Problem

Many emotional wellness applications feel generic and emotionally disconnected, providing the same guidance to every user regardless of personality, emotional state, or social energy.

## Solution

InnerSync adapts emotional guidance based on MBTI personality patterns, emotional energy, stress levels, and social battery conditions to create a more human-centered emotional support experience.

## Goal

Create a calming and emotionally intelligent interface that feels personal instead of robotic while exploring adaptive Human-Computer Interaction (HCI) systems for emotional wellbeing.

---

## Research Motivation

This project explores how emotionally adaptive interfaces can improve user wellbeing through personality-aware interaction systems and AI-assisted emotional support.

The interface investigates the relationship between emotional analytics, burnout patterns, emotional recovery systems, and adaptive UI recommendations based on MBTI personality traits.

---

## Features

- MBTI-adaptive emotional guidance
- Emotional analytics dashboard
- Personality-aware AI support
- Adaptive wellness recommendation system
- Calm glassmorphism interface
- Responsive interaction design
